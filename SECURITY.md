# Security Policy

## Supported Versions

The latest alpha release is the currently supported version.

## Reporting a Vulnerability

Do not disclose vulnerability details in a public issue.

GitHub private vulnerability reporting is not currently enabled for this repository.

First, create a GitHub issue titled `Security contact request` without including vulnerability details. A maintainer will arrange a confidential channel for the report.

If the repository displays `Report a vulnerability`, prefer GitHub's private vulnerability reporting form at <https://github.com/nxnminieye/nexa/security/advisories/new>.
